# Rendre son travail (étudiants M2)

Tu es sur le dépôt de référence. **Ne travaille pas dessus directement.**

1. **Fork** ce dépôt (bouton *Fork*) → tu obtiens `TON-COMPTE/BugBounty`.
2. Clone **ton fork**, pas celui-ci.
3. Travaille, commit, `git push origin main` : ton fork est ton rendu.

Guide détaillé : [docs/07-guide-etudiant.md](docs/07-guide-etudiant.md).

## Ouvrir une Pull Request (si le formateur le demande)

Depuis ton fork : **Contribute → Open pull request**.
La PR sert à faire relire un livrable précis, pas à pousser tout ton travail.

## Avant tout push / toute PR

- [ ] Aucun secret (`.env`, tokens, cookies) — respecte `.gitignore`
- [ ] Aucune vraie donnée personnelle / dump client
- [ ] Uniquement des cibles **autorisées pour le cours**
- [ ] Messages de commit clairs, en français
